### Jawaban 12.2

1. Pada single linked list, setiap node hanya memiliki satu pointer yang menunjuk ke node berikutnya, sehingga traversal hanya dapat dilakukan dalam satu arah. Sedangkan pada double linked list, setiap node memiliki dua pointer, satu menunjuk ke node berikutnya dan satu lagi menunjuk ke node sebelumnya, sehingga traversal dapat dilakukan dalam dua arah.
2. Atribut next pada class Node digunakan untuk menunjuk ke node berikutnya dalam linked list, sehingga memungkinkan traversal ke depan. Sedangkan atribut prev digunakan untuk menunjuk ke node sebelumnya, sehingga memungkinkan traversal ke belakang. Dalam manipulasi node, next digunakan untuk menghubungkan node baru dengan node berikutnya, sementara prev digunakan untuk menghubungkan node baru dengan node sebelumnya.
3. Konstruktor pada class DoubleLinkedList digunakan untuk menginisialisasi kondisi awal linked list dengan menetapkan head dan tail ke null. Hal ini menunjukkan bahwa linked list dalam keadaan kosong saat pertama kali dibuat, sehingga tidak ada node yang terhubung.
4. Karena jika linked list masih kosong  maka head dan tail sama dengan newNode, sehingga head dan tail akan menunjuk ke node yang sama. Karena linked list hanya memiliki satu node.
